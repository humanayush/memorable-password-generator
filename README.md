**[🔗 View Live Demo](https://humanayush.github.io/memorable-password-generator/)**

## 📖 Overview
Generating secure passwords often results in random strings of characters that are impossible to remember. This project solves that by creating passphrases that combine random words, numbers, and symbols, making them tough for computers to crack but easy for humans to recall.

## ✨ Features
* **Strong and Memorable passwords:** Helps to create passwords that are secured and easy to memorize.
* **Special Characters & Numbers:** Toggle options to include numbers and symbols for extra security.
* **One-Click Copy:** Easily copy the generated password to your clipboard.
* **Fully Responsive:** Works seamlessly on desktop, tablet, and mobile devices.
